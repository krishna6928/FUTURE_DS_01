# FUTURE_DS_01

## Superstore Sales & Business Performance Analysis

### 📌 Project Overview

This project focuses on analyzing Store Sales data using Microsoft Power BI to understand sales performance, product performance, customer purchasing patterns, regional sales, and business profitability.

### 🎯 Objective

To evaluate store sales performance, identify sales trends, analyze product and category performance, and understand which regions and products contribute most to overall revenue and profit.

### 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Store Sales Dataset (CSV)

### 📊 Key Analysis

- Overall Store Sales Analysis
- Total Sales by Product Category
- Sales by Region
- Monthly Sales Trends
- Profit by Product Category
- Top-Performing Products
- Customer Sales Analysis
- Regional Performance Analysis
- Sales and Profit Comparison
- KPI Monitoring:
  - Total Sales
  - Total Profit
  - Total Orders
  - Average Sales

### 📁 Files Included

- Power BI Dashboard (`.pbix`)
- Dashboard Screenshot (`.png`)
- Sample - Superstore Dataset (`.csv`)

### 💡 Project Outcome

The dashboard provides an overview of store sales performance, product trends, regional sales, and profitability. It helps identify business opportunities and supports data-driven decision-making.
